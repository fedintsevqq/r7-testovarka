# Корпус реальных файлов

Сюда кладут обезличенные файлы клиентов: `.xlsx`, `.xls`, `.ods`, `.csv`.
`python -m r7 corpus` открывает каждый в Р7, пересчитывает, экспортирует
и строит матрицу «файл × шаг». Подробности — `docs/corpus.md`.

## Правила

1. **Только обезличенные файлы.** Перед тем как положить файл, уберите
   персональные данные: ФИО, телефоны, почту, паспорта, ИНН, СНИЛС, адреса,
   номера счетов и договоров. Замените их похожими по виду и длине: формулы,
   объём и структура должны остаться, люди — нет.
2. **Проверьте свойства документа.** Автор, компания, комментарии к ячейкам,
   скрытые листы и имена в «Диспетчере имён» тоже бывают личными.
3. **Только для команды.** Папка `Corpus/` в `.gitignore`: файлы и
   `corpus.toml` в репозиторий не попадают. Не выкладывайте их в общие
   чаты и трекер. Инструмент файлы никуда не отправляет.
4. **Отчёт наружу — с `--hide-names`.** Тогда в JSON и HTML вместо имён
   файлов стоят их id (начало sha256), а заметки из манифеста убраны.
5. **Файл не меняется.** Р7 открывает копию во временной папке, исходник
   не трогает. Копия удаляется после файла.

## Манифест

`corpus.toml` необязателен. Без него каждый файл проходит все шаги с
экспортом в PDF. Пример — `corpus.example.toml`: скопируйте его в
`corpus.toml` и поправьте под свои файлы.
