# R7 Тестоварка — Инструмент для тестирования производительности Р7-Офис

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## О проекте

Это приложение с графическим интерфейсом (Tkinter) для автоматизации установки
различных версий Р7-Офис и проведения нагрузочного тестирования.

Пользователь может легко переключаться между версиями, запускать комплекс тестов
(открытие файлов, копирование, вставка, работа с формулами ВПР) и получать
подробный отчёт в форматах HTML и Excel.

---

## Установка и запуск

### Требования

- Python **3.10** или выше (64-bit)
- ОС Windows
- Права администратора для установки/удаления версий Р7-Офис

### 1. Клонирование репозитория

```bash
git clone https://github.com/fedintsevqq/r7-testovarka.git
cd r7-testovarka
```

### 2. Виртуальное окружение (рекомендуется)

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск

```bash
python r7_Testovarka.py
```

> **Важно:** запускайте от имени Администратора для установки/удаления версий.

## Как пользоваться

### Вкладка «Версии»

Выберите `.exe` или `.msi` файл из папки `Distributives/` и нажмите **«Установить»**.
Программа автоматически определит текущую установленную версию Р7-Офис через реестр.

### Вкладка «Производительность»

Нажмите **«Старт»** — приложение запустит Р7-Офис, эмулирует действия пользователя
через `pyautogui` и замерит время выполнения **13 операций**:

- открытие файла
- копирование и вставка данных
- вычисление формул ВПР
- пересчёт, прокрутка, навигация по листам
- замер потребления RAM и CPU

Результат автоматически сохраняется в `Performance_Report.html` и `Performance_Report.xlsx`.

### Batch-режим

Позволяет прогнать один и тот же тест последовательно по нескольким версиям
и получить сводный HTML-отчёт со сравнительными таблицами.

## Структура проекта

```
r7-testovarka/
├── r7_Testovarka.py        # Основной скрипт приложения
├── requirements.txt        # Зависимости Python
├── BUILD.md                # Инструкция по сборке в .exe (PyInstaller)
├── Distributives/          # Папка для установщиков .exe/.msi (добавить вручную)
├── TestFiles/              # Тестовые .xlsx файлы (создаются автоматически)
└── Reports/                # HTML-отчёты и данные JSON (создаются автоматически)
```

> Папки `TestFiles/` и `Reports/` создаются при первом запуске автоматически.
> Файлы-дистрибутивы в `Distributives/` нужно положить вручную.

## Зависимости

| Пакет | Назначение |
|-------|-----------|
| `pyautogui` | Эмуляция действий пользователя (клики, ввод текста) |
| `pyperclip` | Работа с буфером обмена |
| `openpyxl` | Создание и чтение Excel-файлов |
| `pywin32` | Win32 API: управление окнами, реестр |
| `psutil` | Мониторинг RAM и CPU |

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: pyautogui` | `pip install pyautogui` |
| Не удаляет старую версию | Запустите от имени **Администратора** |
| Не кликает по кнопкам Р7-Офис | Убедитесь, что масштаб экрана **100%**, приложение на основном мониторе |
| Окно обновления блокирует тест | Программа закрывает его автоматически через Win32 API |
