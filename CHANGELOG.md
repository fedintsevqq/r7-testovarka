# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[семантические](https://semver.org/lang/ru/). Версия инструмента живёт в
`r7/version.py`; релиз — тег `v<версия>` на коммит, сборку и GitHub Release
делает `.github/workflows/build.yml`. Номера в скобках — pull request'ы.

Отчёты разных схем замера (`measure_schema`) напрямую не сравниваются; какие
схемы что меняли — `docs/adr/0003-measure-schemas.md`.

## [1.2.1] — 2026-10-09

### Исправлено

- «Папка…» (бывшая «Добавить папку») вешала приложение: после импорта
  `pywinauto` процесс живёт с `coinit_flags=0`, и диалог Tk
  `askdirectory` не открывался вовсе. Выбор папки теперь — системный диалог
  «Обзор папок» (`SHBrowseForFolder`) в отдельном потоке, окно не замирает;
  ошибка диалога попадает в журнал и строку статуса.
- Подсказки у кнопок появлялись не у кнопки, а где-то вверху экрана: окно
  показывалось раньше, чем задавалась позиция. Теперь размер и позиция
  заданы до показа, подсказка стоит под кнопкой по центру, а у нижнего края
  экрана — над ней.
- «Файл…» (бывшая «Добавить») копирует дистрибутив в фоне: 430–630 МБ на
  главном потоке замораживали окно.
- Кнопки вкладки «Версии» переименованы коротко и ясно: «Папка…»,
  «Файл…», «Найти в Загрузках»; «Открыть папку» и «Обновить» — значки с
  подсказкой.

## [1.2.0] — 2026-10-09

PR #141–#145.

### Добавлено

- Дистрибутивы из нескольких папок: «Добавить папку» на вкладке «Версии» (в том
  числе сетевая папка команды, файлы не копируются), «Поискать в Загрузках»

  файлы, подписанные АО «Р7»; неподписанный или подменённый файл отклоняется с
  причиной в журнале.
- Мастер первого запуска предупреждает, если памяти меньше 8 ГБ: пик RAM Р7 на
  таблице 50К около 5 ГБ, замеры пойдут в подкачку.

  другом, таблица прокручивается внутри с закреплённой шапкой и колонками
  «Операция» и «Порог» (#143).
- README: раздел «Как пользоваться», свежие скриншоты (#143); текст GitHub
  Release — из раздела CHANGELOG (#142); файлы `.sha256` с LF (#141).

### Исправлено

- Установщик Inno пишет номер сборки в название программы: в шапке окна номер
  шёл дважды, а в трендах одна сборка считалась двумя версиями (#143).

## [1.1.0] — 2026-10-08

Первый выпуск для команды: версия 1.0.0 отдельно не выпускалась, её изменения
(раздел [1.0.0] ниже) входят и сюда. PR #106–#139, 07–08.10.2026.

### Главное

- **Три редактора.** Кроме таблиц меряются документы (.docx) и презентации
  (.pptx): во вкладке, в Batch, из командной строки, с теми же отчётами.
- **Вердикт по шуму вашего ПК.** Порог регрессии берётся из A/A-прогона
  стенда, с 95 %-интервалом и поправкой на число тестов; шумный прогон сам
  добирает повторы.
- **Поиск виновной сборки.** `python -m r7 bisect` ставит сборки по очереди и
  находит первую, на которой операция стала медленнее; Batch проверяет дрейф
  стенда сэндвичем A-B-A. Оба проверены живьём с переустановкой Р7.
- **Улики для тикета.** Трасса движка и профиль V8 при регрессии, пакет улик
  с готовым текстом тикета, корпус реальных файлов, свои тесты плагинами.
- **Быстрее.** Набор smoke — 187 с вместо 308, окно открывается за 0,3 с.

### Добавлено

- Трасса движка и профиль V8 при регрессии: `python -m r7 run
  --trace-regressions` (или `trace_on_regression` в `r7_settings.json`) после
  прогона повторяет операции с регрессией или «вероятной регрессией» к
  эталону один раз с трассой. Повтор идёт вне замера и в медиану не входит.
  Файлы `<ts>_<операция>.trace.json` (Perfetto) и `.cpuprofile` лежат рядом с
  отчётом, разбивка по фазам — в ключе `diagnostics` полного JSON (схема та
  же), ссылки — на странице готовности, файлы — в пакете улик.
  `python -m r7 trace --op …` снимает трассу по требованию (#111).
- Бисект по сборкам: `python -m r7 bisect --good … --bad … --op …` ставит
  дистрибутивы по очереди и находит первую сборку, на которой операция
  медленнее базы. Пропуск неизмеримых сборок, добор повторов, возврат
  исходной версии в конце, страница `bisect_<ts>.html` (`docs/cli.md`) (#112).
- Плагины тестов: файл `plugins/*.py` рядом с программой объявляет
  `register(ops)` и возвращает `(имя, функция с .prepare)` по контракту
  `SpreadsheetOps.tests()`. Тест появляется во вкладке с пометкой «плагин», в
  Batch, наборах и командной строке; в записи результата — поле `plugin` с
  именем файла (схема та же). Сломанный плагин пропускается с
  предупреждением. Плагин выполняется с правами инструмента: выключатель
  `plugins_enabled` в `r7_settings.json` и `python -m r7 --no-plugins`.
  Пример — `docs/plugins/example_bold_column.py`, контракт —
  `docs/plugins.md` (#114).
- Корпус реальных файлов: `python -m r7 corpus` открывает каждый файл из
  `Corpus/` (копию во временной папке), меряет открытие, полный пересчёт
  (`asc_calculate`) и экспорт, пишет матрицу «файл × шаг»
  (`corpus_<ts>.json`, `.html`). `corpus-compare` строит «файл × версия» с
  вердиктами и поправкой на семью. Манифест `Corpus/corpus.toml`,
  `--hide-names` для передачи отчёта наружу; файлы клиентов в `.gitignore`
  (`docs/corpus.md`). Проверка экспорта в `xlsx` (#115).
- Документы .docx (этап 5, часть первая): набор `suites/docs.toml`
  (`[suite] editor = "document"`) — открытие, вставка 100 страниц, смена
  стиля всего документа, поиск и замена, экспорт в PDF и DOCX. Фикстура
  `r7-test-doc-100p.docx` создаётся сама; готовность и конец операции
  учитывают досчёт вёрстки; повторы откатываются по истории правок. В
  `performance_full_*.json` новый ключ `editor` (схема не менялась).
  Живой проверки ещё не было — `docs/document-ops.md` (#116).
- Презентации .pptx (этап 5, часть вторая): набор `suites/slides.toml`
  (`[suite] editor = "presentation"`) — открытие, добавление 50 слайдов,
  дублирование всех слайдов, смена темы, переход ко всем слайдам, экспорт в
  PDF и PPTX. Фикстура `r7-test-slides-50.pptx` создаётся сама; готовность —
  по кнопке «Добавить слайд» и устоявшемуся числу слайдов; повторы
  откатываются по истории правок. В отчёте `"editor": "presentation"`.
  Проверка экспорта в PPTX и ODP. Живой проверки ещё не было —
  `docs/presentation-ops.md` (#117).
- Свойства статистики на Hypothesis: симметрия Манна-Уитни и точного p,
  p в [0, 1], поправка Бенджамини-Хохберга, независимость вердикта от единиц
  измерения, медиана и MAD, `detect_leak` и точки смены уровня на ровном ряде
  (`tests/test_stats_properties.py`) (#108).
- Эталонные HTML-отчёты: прогон, сравнение, тренды, сводка Batch, готовность
  релиза и свой файл собираются из JSON в `tests/fixtures/golden/` и
  сравниваются с эталоном; `R7_UPDATE_GOLDEN=1` переписывает эталоны (#108).
- Релиз: SBOM в формате CycloneDX и список лицензий сторонних пакетов
  прикладываются к GitHub Release; необязательная подпись `.exe`, если в
  репозитории заведён сертификат (#108).
- Архитектурные решения в `docs/adr/`: CDP вместо клавиш, порт 8080, схемы
  замера 7, 9 и 10, `_pace`, медиана с MAD и интервал с поправкой (#108).
- `CHANGELOG.md` — история изменений по версиям (#108).
- Документы и презентации из окна: на вкладке «Производительность» над
  списком тестов переключатель «Таблица (.xlsx) / Документ (.docx) /
  Презентация (.pptx)». Смена пересобирает список: свои тесты и повторы по
  умолчанию, плагины только у таблиц. `selected_tests.json` хранит выбор
  каждого редактора и последний редактор; старые форматы читаются как выбор
  таблиц (`docs/ui-and-reports.md`).
- Документы и презентации наравне с таблицами в трёх местах:
  - метрики интерфейса (схема 10) теперь снимаются и у документа и
    презентации: взвод и сбор идут прологом редактора
    (`EditorProfile.api_prelude`), раньше поля оставались пустыми;
  - трасса регрессий: `run --trace-regressions` больше не пропускает наборы
    документа и презентации, `trace --op` сам находит редактор по имени
    операции, `--editor` задаёт его явно;
  - Batch по версиям: в диалоге переключатель редактора, фикстура
    подставляется или создаётся, тип файла проверяется; A-B-A работает так
    же; сводка Batch показывает редактор и прячет ВПР у документа и
    презентации (`docs/document-ops.md`, `docs/presentation-ops.md`)
    (#119, #120).
- Добор повторов (схема 11): после заказанных повторов вкладка и Batch
  добавляют повторы, пока 95 %-интервал медианы шире половины порога теста,
  но всего не больше заказанных × 2. В записи операции — `n_added`,
  `ci_target_pct`, `ci_halfwidth_pct`; выключается `adaptive_runs: false`
  (`docs/statistics.md`) (#123). Если время монотонно дрейфует от повтора к
  повтору (критерий Манна-Кендалла), добор не идёт: он лишь тянул бы медиану
  за дрейфом (#128).
- Профиль шума стенда снят живым A/A (`Reports/noise_profile.json`): пороги
  сравнения — по шуму стенда, а не 10 % по умолчанию (#128).

### Изменено

- Линтер ruff вместо pyflakes (правила `E, F, B, S, PL, C90`, у каждого
  отключённого правила — причина в `pyproject.toml`), mypy для `stats`,
  `config`, `run_state`, `noise`, `changepoint`, `r7_reports`; оба — шаги CI
  и pre-commit (#107).
- `.gitignore` больше не прячет JSON-фикстуры тестов: игнорируются только
  JSON в корне программы и в `Distributives/` (#107).
- Граница Windows-кода: `win32*`, реестр, `pywinauto` и `ctypes.windll`
  зовутся только из `r7/windows.py` и `r7/env.py` (плюс реестр в
  `r7/versions.py` и x2t в `r7/x2t_files.py`). Тест
  `tests/test_platform_boundary.py` не пропустит новый вызов в другом модуле;
  список старых нарушителей пуст. Поведение не менялось (#107, #113).
- mypy в строгом режиме — для следующих модулей `r7/`, примеси проверяются через
  `Protocol` (`OpWaitHost`, `CloseWaitHost`, `ReadinessWaitHost`,
  `UxMetricsHost`, `PrepHost`) (#122, #124, #127, #130, #133).
- Прогон быстрее, замер прежний:
  - повтор «Вставки большого массива» откатывается удалением листа вставки
    (0,5 с) и очисткой истории правок вместо отмены вставки через историю
    (17–22 с); smoke.toml — 308 → 196 с (#129);
  - экспорт не ждёт 3 с предупреждения о потере функций там, где его нет
    (XLTX, PDF, DOCX, PPTX), и набирает путь без паузы между клавишами:
    повтор экспорта короче на 2–4 с (#131);
  - нет безусловной паузы 0,5 с после каждого повтора: простой Р7 и так
    проверяется после отката и перед секундомером (#134);
  - окно создаётся за 0,3 с вместо 0,9 с: обход виджетов на
    `<<ThemeChanged>>` — один на пачку событий, а не на каждый виджет (#129).

### Исправлено

- Многодокументный сценарий закрывает все окна Р7 и убирает lock-файлы
  фикстур: lock-файл от добитого окна ставил следующий запуск на диалог
  блокировки, и коннектор цеплялся к чужому документу (#106).
- Поправка Бенджамини-Хохберга могла дать скорректированный p на единицу
  младшего разряда меньше сырого (округление `p · m / m`). Нашёл
  Hypothesis (#108).
- Экспорт: после сохранения в ODS заголовок окна документа меняется на
  «temp_export….ods — Р7-Офис», и поиск диалога-предупреждения формата
  принимал за диалог само окно документа. Настоящий диалог перед XLTX
  теперь нажимается (#109).
- Живой набор тестов искал окно Р7 по заголовку и принимал за него вкладку
  Chrome «Техническая поддержка Р7-Офис»; теперь только окна процессов
  Р7 (#110).
- Документы и презентации: конец операции ждёт досчёта вёрстки до пинга, шаг
  опроса — 0,05 с вместо 0,15 с; хвост вёрстки «Вставки 100 страниц» больше
  не теряется, «Смена стиля» не завышается на шаг опроса (#125).
- Смена темы падала с `TclError`, если до этого открывали и закрывали окно
  Batch или сравнения, и выбор темы не сохранялся (#126).
- `nightly_local.py --aa`: строки x2t второго прогона шли дважды —
  отслеживатель x2t первого приложения не останавливался (#128).
- Подготовка ВПР проверяет, что формулы легли в буфер обмена; иначе —
  ошибка подготовки, а не замер пустой вставки (#132).
- Batch и бисект не могли удалить версию, поставленную из `.exe`: установщик
  Inno Setup пишет в реестр `unins000.exe`, а удаление принимало только
  `msiexec /X{GUID}`. Деинсталлятор Inno теперь принимается так же строго —
  запись из HKLM, файл `unins###.exe` прямо в папке установки этой записи,
  рядом exe Р7, только ключи тишины; конец удаления — исчезновение
  `unins000.exe`. Цикл переустановки пройден живьём: тихая установка Inno,
  бисект и Batch A-B-A (#137).
- Бисект: в таблице у «плохой» сборки стоял класс «как регрессия» и пустые Δ,
  даже когда она быстрее базы (#138).
- A-B-A в Batch брал порог дрейфа 10 % вместо порога по шуму стенда и
  объявлял дрейф по XLTX, который x2t конвертирует то за 5, то за 11 с (#139).

## [1.0.0] — 2026-10-07

Первая версия с номером. Собрана по этапам 0–3 плана
`docs/plan-to-20.md`. Тег `v1.0.0` ещё не поставлен.

### Безопасность (этап 0)

- Команда удаления версии из реестра выполняется, только если это `msiexec`
  из System32 с одним `/X{GUID}`; иначе ничего не запускается. После
  удаления стирается только папка `InstallLocation` той же записи реестра, с
  предохранителями, а не `C:\Program Files\R7-Office` по жёсткому пути (#91).
- Перезапуск от администратора: параметры в кавычках, результат UAC
  проверяется, при отказе программа работает без прав (#91).
- Зависимости из `requirements.lock` с хешами, `pip-audit` в CI, действия
  GitHub закреплены по SHA, Dependabot для pip и actions (#89, #92–#94).
