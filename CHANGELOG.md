# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[семантические](https://semver.org/lang/ru/). Версия инструмента живёт в
`r7/version.py`; релиз — тег `v<версия>` на коммит, сборку и GitHub Release
делает `.github/workflows/build.yml`. Номера в скобках — pull request'ы.

Отчёты разных схем замера (`measure_schema`) напрямую не сравниваются; какие
схемы что меняли — `docs/adr/0003-measure-schemas.md`.

## [Unreleased]

## [1.0.0] — 2026-10-07

Первая версия с номером. Собрана по этапам 0–3 плана
`docs/plan-to-20.md`. Тег `v1.0.0` ещё не поставлен.

### Безопасность (этап 0)

- Команда удаления версии из реестра выполняется, только если это `msiexec`
  из System32 с одним `/X{GUID}`; иначе ничего не запускается. После
  удаления стирается только папка `InstallLocation` той же записи реестра, с
  предохранителями, а не `C:\Program Files\R7-Office` по жёсткому пути (#91).
- Перезапуск от администратора: параметры в кавычках, результат UAC
  проверяется, при отказе программа работает без прав (#91).
- Зависимости из `requirements.lock` с хешами, `pip-audit` в CI, действия
  GitHub закреплены по SHA, Dependabot для pip и actions (#89, #92–#94).

### Добавлено

- Файловый журнал `Reports/logs/r7-testovarka.log` с ротацией; необработанные
  исключения потоков и Tk пишутся туда, жёсткое падение — в `crash.log` (#90).
- Ключи тихой установки по типу дистрибутива: msi, Inno Setup, NSIS (#91).
- Рабочая фикстура в латинице `r7-test-50k.xlsx`, прежнее кириллическое имя
  узнаётся (#96).
- Версия инструмента в `r7/version.py`, проверка обновлений в GitHub
  Releases, `tool_version` в JSON-отчёте (#96).
- Архив «распаковал и запустил» `R7-Testovarka-<версия>-win64.zip` и
  GitHub Release на теге `v*` (#96).
- Настройки на машину `r7_settings.json`: путь к Р7 выше реестра, папка
  отчётов, повторы по умолчанию (#97).
- Режим без прав администратора: замеры идут, сброс кэша ОС и установка
  версий отключены с объяснением (#97).
- Мастер первого запуска: сборка, права, Р7 найден и где искали, порт CDP,
  фикстура, диск, масштаб, пакеты (#97).
- Чеклист проверки сборки на чистых ПК (#95).
- В отчёте сборка Р7 (номер, sha256 и дата exe, дистрибутив), отпечаток
  машины и индекс скорости стенда; сравнение и тренды предупреждают «другой
  стенд» (#98).
- Общая папка отчётов команды и фильтр по машине на странице трендов (#98).
- Командная строка `python -m r7 run|suites|check`, наборы тестов
  `suites/*.toml` с бюджетами, экран «Релиз готов / Не готов», JUnit XML (#99).
- Пакет улик для бага: zip с отчётами, сравнением, окружением, журналом и
  готовым текстом тикета (#100).
- Вкладка «Сценарии»: soak, многодокументный, восстановление после
  падения (#100).
- Статистика сравнения: bootstrap-интервал изменения медианы, сдвиг
  Ходжеса-Лемана, точный p Манна-Уитни при n ≤ 8, вердикты «эквивалентно» и
  «не определено», поправка Бенджамини-Хохберга на операции, минимальный
  обнаружимый эффект. Описание — `docs/statistics.md` (#104).
- Профиль шума стенда из A/A-прогона (`tests/nightly_local.py --aa`): порог
  теста `max(3 × CV, 2 %)`, без профиля 10 % (#104).
- «Вероятная регрессия»: интервал за порогом и сырой p прошёл, а после
  поправки нет (#104).
- План питания «Высокая производительность» на время прогона с возвратом
  прежнего; частота CPU из PDH и пометка троттлинга у повтора (#105).
- Метрики интерфейса: время до первого кадра, самая долгая блокировка,
  JS-куча после операции (#105).
- Ночное сравнение с базой из пяти сравнимых ночей вместо одной прошлой (#103).
- Точки смены уровня на трендах: «сдвиг с <сборка>, +N %» (#103).
- Сэндвич A-B-A в Batch: базовая версия повторяется в конце, дрейф стенда
  помечает сводку (#103).

### Изменено

- Схема замера 9 → 10: план питания, частота CPU и метрики интерфейса в
  JSON. Старые ключи на месте (#105).
- `.exe` собирается без UPX (#89).

### Исправлено

- Закрытие Р7 жмёт «Нет» на каждый вопрос «Сохранить изменения?», а не только
  на первый (#101).
- Штатное закрытие Р7 больше не сопровождается аварийным: инструмент ждёт,
  пока процессы уйдут (#102).
- Сдвиги на трендах ищутся только со схемы 7: смены методики больше не
  выглядят как «+941867 %» (#103).
