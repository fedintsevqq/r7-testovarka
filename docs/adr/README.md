# Архитектурные решения (ADR)

Короткие записи о решениях, которые трудно понять по коду: что было, что
выбрали и чем за это платим. Формат — облегчённый MADR: «Контекст»,
«Решение», «Последствия». Цифры и даты — из `docs/` и истории PR, не из
памяти.

| № | Решение |
|---|---|
| [0001](0001-cdp-instead-of-keys.md) | Операции через CDP (`asc_*`-api), клавиши — запасной путь; откат на клавиши только при `mutated = false` |
| [0002](0002-cdp-port-8080.md) | CDP-порт 8080, запасные 8081 и 8082, иначе прогон без CDP |
| [0003](0003-measure-schemas.md) | Схемы замера 7, 9 и 10: что меняли и почему отчёты разных схем не смешивать |
| [0004](0004-pace-and-paused-time.md) | `_pace`: паузы инструмента вычитаются из замера, но только пока Р7 простаивает |
| [0005](0005-median-mad-interval-bh.md) | Медиана и MAD, порог из шума стенда, интервал и поправка Бенджамини-Хохберга |

Новое решение — следующий номер, файл `NNNN-коротко-латиницей.md`, строка в
этой таблице. Решение поменялось — новая запись со ссылкой на старую, а в
старой статус «заменено NNNN».
