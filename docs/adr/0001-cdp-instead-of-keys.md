# 0001. Операции через CDP, клавиши — запасной путь

Статус: принято. Подробности — `docs/cdp-operations.md`, `docs/precision.md`.

## Контекст

Сетка Р7 рисуется на `<canvas>`: ячеек, строк и столбцов в разметке нет.
Клавиатурный путь (pyautogui) меряет не только Р7, но и оконный менеджер,
отрисовку меню и модалок, а конец операции приходилось угадывать по загрузке
CPU с разрешением около 0,3 с. Ctrl+A на нём давал 0,84 / 1,88 / 0,84 с при
вызове api 0,84 с: детектор принимал фоновую сборку мусора за продолжение
операции. `document.execCommand` и `navigator.clipboard` не годятся:
`selectAll` выделит HTML страницы, а не лист, вставка из скрипта отключена в
движках, команд вставки столбца или листа там нет.

## Решение

- Операции правки вызывают `asc_*`-методы экземпляра `Asc.spreadsheet_api`
  через Chrome DevTools Protocol — те же методы, что дёргают кнопки
  тулбара. Р7 запускается с `--ascdesktop-support-debug-info`. На момент
  перехода так пошли 7 из 13 операций (таблица в `docs/cdp-operations.md`);
  ВПР, удаление столбца и сохранение в PDF остались на клавишах.
- Конец операции на CDP-пути — пинг редактора (`_wait_renderer_idle`,
  разрешение около 1 мс), а не опрос CPU.
- Клавиши остаются запасным путём, если CDP в этом запуске нет (пакетов нет,
  порт занят, api не найден). Цифры двух путей между собой не сравниваются.
- Откат на клавиши разрешён, только если документ гарантированно не тронут.
  Признак — поле `mutated` в ответе JS: его ставит шаг прямо перед изменяющим
  вызовом (`asc_Paste`, `asc_addWorksheet`, `asc_insertCells`). `None` от
  `evaluate()` может значить «операция уже ушла в Р7 по таймауту сокета», и
  повтор клавишами применил бы правку дважды. Поэтому изменяющий шаг в
  цепочке всегда последний (CLAUDE.md, правило 7).
- Результат проверяется по снимкам документа до и после вызова; не
  подтвердился — прогон `unverified` и в медиану не входит (схема 8).

## Последствия

- Цифра операции — работа Р7, а не инструмента; разброс Ctrl+A ушёл.
- `api_ms` у вставок занижен: основная работа идёт после возврата из функции.
  Смотреть надо на `time`.
- К уже запущенному без флага Р7 CDP не подключить — перед прогоном Р7 должен
  быть закрыт.
- Без CDP рабочий лист не выбрать и повторы не откатить; тесты «ПКМ» и «меню
  Вставка» без CDP честно падают, а не жмут вслепую (`docs/ui-fallback.md`).
- Выключатель `CDP_OPS_ENABLED` возвращает всё на клавиши — для сверки путей
  на одной сборке.
