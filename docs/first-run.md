# Первый запуск на новом ПК

Инструмент разъезжается по машинам команды, и первый отчёт должен получиться
без автора рядом. За это отвечают три вещи: мастер первого запуска,
файл настроек `r7_settings.json` и режим без прав администратора.

## Мастер первого запуска

Открывается при старте, пока в `r7_settings.json` нет `"first_run_done": true`
(`r7_Testovarka.py`, `__main__`, после сборки `R7Testovarka` и до показа
главного окна). Проверки живут в `r7/firstrun.py` (без Tk), окно в
`r7/ui/firstrun_dialog.py`. Каждая проверка отвечает именем, статусом,
деталью и подсказкой «что сделать»:

| Проверка | Статус при проблеме | Откуда берётся |
|---|---|---|
| Сборка программы: модули, зависимости, шаблоны | ✗ fail | `r7/selfcheck.py` (то же, что `--self-check`) |
| Права администратора | ! warn | `r7/privileges.py` |
| Р7-Офис найден (и где искали, если нет) | ✗ fail | `_find_r7_path`, список мест в `_r7_path_searched` |
| Р7-Офис сейчас закрыт | ! warn | `_get_r7_processes` |
| Порт CDP 8080 свободен | ! warn | `ReadinessMixin._cdp_port_free` |
| Тестовый файл 50К (кириллическое или латинское имя `r7-test-50k*.xlsx`) | ✗ fail | `batch_config.find_test_file` |
| Свободно 5 ГБ на диске отчётов | ! warn | `shutil.disk_usage` |
| Масштаб экрана 100 % | ! warn | `_get_dpi_scale_pct` |
| Пакеты Python (CDP, pywinauto, psutil и т. д.) | ! warn | флаги `r7/env.py` |

«Продолжить» доступна, когда нет ✗. «Повторить проверку» выполняет всё
заново (исправили, не закрывая окно). Флажок «Больше не показывать» пишет
`first_run_done` в настройки. Крестик закрывает окно при любом исходе: провал
означает только, что пользователь увидел проблему, главное окно открывается
всё равно. `tests/ci_preflight.py` берёт проверки «Р7 закрыт» и «Р7 найден»
отсюда же.

Окно создаётся, пока корень Tk скрыт (`withdraw`), поэтому не делается
`transient` к нему: transient-окно повторяет состояние хозяина и тоже
осталось бы невидимым.

## r7_settings.json

Лежит рядом с программой (`config.BASE_DIR`), правится руками. Модуль
`r7/settings.py`: `load_settings()` никогда не бросает (нет файла: умолчания
молча; битый файл: умолчания и одно предупреждение в журнал),
`save_settings(data)` возвращает `False`, если не записалось, `get(key)`
даёт действующее значение.

```json
{
  "r7_path": "D:\\Soft\\R7-Office\\Editors\\DesktopEditors.exe",
  "reports_folder": "D:\\R7-Reports",
  "default_runs": 5,
  "team_reports_folder": null,
  "first_run_done": true
}
```

| Ключ | Что делает |
|---|---|
| `r7_path` | Путь к `DesktopEditors.exe`. Выше реестра: если файл есть, реестр не читается, в журнале «путь к Р7 из r7_settings.json». Если файла нет, предупреждение и обычный поиск |
| `reports_folder` | Папка отчётов вместо `Reports` рядом с программой. Недоступная папка: предупреждение в журнал и штатная `Reports` |
| `default_runs` | Повторы по умолчанию для тестов правки (в пределах `RUNS_MIN..RUNS_MAX`); экспорты и открытие не трогает |
| `team_reports_folder` | Общая папка команды, задел под этап 2 плана |
| `manage_power_plan` | `true` по умолчанию: на время прогона план питания «Высокая производительность» вместо «Сбалансированной» или «Экономии энергии», после — прежний; свой план стенда не трогается (`r7/stand.py`). `false` — план не трогать |
| `distributives_dirs` | список папок с дистрибутивами Р7 помимо `Distributives/` — локальных или сетевая папка команды. Файлы не копируются. Пополняется кнопками «Папка…» и «Найти в Загрузках» на вкладке «Версии» (`r7/distributives.py`, `docs/versions.md`) |
| `plugins_enabled` | `true` по умолчанию: тесты из `plugins/*.py` рядом с программой появляются в списке (`r7/plugins.py`, `docs/plugins.md`). Плагин выполняется с правами инструмента, часто от администратора: только доверенные файлы. `false` — не загружать |
| `first_run_done` | Мастер первого запуска больше не показывать |

Порядок поиска Р7 без `r7_path`: `InstallLocation` записи реестра, кэш
прошлого вызова, типовые пути на `C:\Program Files`, обход `Program Files` на
всех дисках. Если ничего не нашлось, журнал перечисляет все места
(`Р7-Офис не найден. Искали: …`), а использование запасного пути тоже пишется в
журнал. `ui_settings.json` (тема) и `selected_tests.json` (выбор тестов)
остаются отдельными файлами.

## Без прав администратора

Права нужны только двум вещам: установке и удалению версий (msiexec) и сбросу
файлового кэша ОС перед холодным стартом (`_purge_os_file_cache`). Проверка
одна, `r7/privileges.is_admin()` (кэшируется, при любой ошибке `False`);
тесты подменяют её в одном месте.

Без прав:

- прогон вкладки «Производительность» и тест своего файла идут как обычно;
- сброс кэша ОС пропускается с одной строкой в журнале («кэш ОС не сброшен:
  нет прав администратора»), а в «Условия прогона» отчёта попадает метка
  «Запуск без прав администратора: файловый кэш ОС не сбрасывался — открытие
  файла могло быть тёплым» (`_note_os_cache_not_purged` дописывает её в
  `_run_environment["warnings"]`, снятый до сброса);
- Batch отказывает с объяснением (он ставит версии);
- кнопка «Установить» на вкладке «Версии» выключена, подсказка «Нужны права
  администратора», текст под таблицей говорит то же.

При старте программа по-прежнему предлагает перезапуск от администратора
(UAC); отказ не мешает работать дальше.
