# R7-Testovarka — первый запуск

Инструмент меряет производительность Р7-Офис — таблиц, документов и презентаций:
открытие файла, операции правки, экспорт. Один `.exe`, Python не нужен. Эта страница кладётся в архив
`R7-Testovarka-<версия>-win64.zip`.

## 1. Распакуйте архив

В любую папку на локальном диске (не на сетевом и не в `Program Files`). После
распаковки рядом с `R7-Testovarka.exe` лежат:

```
R7-Testovarka.exe           программа
R7-Testovarka.exe.sha256    хеш, чтобы сверить скачанный файл
README-first-run.md         эта страница
LICENSE
Distributives\              сюда — дистрибутивы Р7 (.msi/.exe), если нужно ставить версии
TestFiles\                  сюда программа положит тестовые файлы
Reports\                    сюда — отчёты и журнал
```

Сверить хеш (необязательно): `certutil -hashfile R7-Testovarka.exe SHA256` и сравнить
с содержимым `.sha256`. Файл не подписан, SmartScreen может спросить «Выполнить в любом
случае».

## 2. Запустите

Правой кнопкой по `R7-Testovarka.exe` → «Запуск от имени администратора».
Права нужны, чтобы перед холодным стартом сбросить файловый кэш Windows и чтобы
ставить и удалять версии Р7 из `Distributives\`. Без прав программа предупредит
при запуске прогона: замеры без сброса кэша менее воспроизводимы.

При первом запуске мастер проверит стенд: Р7-Офис установлен и закрыт, тестовый файл
на месте, на диске есть место, масштаб экрана известен. Что не так — он напишет
словами; исправьте и запускайте заново.

Р7-Офис на время прогона должен быть закрыт: программа сама его запускает с
отладочным портом и сама закрывает.

## 3. Создайте тестовый файл

Рабочая фикстура (50 000 строк × 50 столбцов, ~33 МБ) в архив не входит — её делает
сама программа, одинаково на любом ПК:

1. Кнопка «📄 Тестовые файлы».
2. Строки `50000`, столбцы `50` — это значения по умолчанию, имя файла подставится само:
   `r7-test-50k.xlsx`.
3. «1. Создать файл». Файл появится в `TestFiles\`, прогон найдёт его сам.

Если у вас уже есть файл `файл-для-теста-Р7-офис-50К.xlsx` с другого стенда — положите
его в `TestFiles\`, программа узнаёт и это имя. Переименовывать не нужно.

## 4. Первый прогон

Вкладка «⚡ Производительность» → отметьте тесты → «▶ Запустить выбранные тесты».
Пока идёт прогон, не трогайте клавиатуру и мышь: программа работает с окном Р7.
Аварийный выход — увести мышь в левый верхний угол экрана.

Полный набор занимает около 45 минут; для знакомства отметьте «Открытие файла» и
пару операций.

## 5. Где что лежит

| Что | Где |
|---|---|
| Отчёт прогона для человека | `Reports\Performance_Report_<время>.html` |
| Те же данные для сравнения версий и трендов | `Reports\performance_full_<время>.json` |
| Журнал программы (прислать при сбое) | `Reports\logs\r7-testovarka.log`, жёсткое падение — `crash.log` рядом |
| Дистрибутивы Р7 для вкладки «Версии» и Batch | `Distributives\` |
| Тестовые файлы | `TestFiles\` |

Версия инструмента пишется в журнал и в JSON отчёта. Когда в GitHub появится новый
релиз, в шапке окна покажется ссылка «Доступна версия X.Y.Z».

Подробнее — `README.md` в репозитории: https://github.com/fedintsevqq/r7-testovarka
